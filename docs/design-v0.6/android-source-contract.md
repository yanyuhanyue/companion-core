## 下一实现边界

1. 复用既有 session / consent / device 校验及 Observation、删除回放；会话显式绑定
   `adb:<serial>`、固定包 `com.max.xiaoheihe`、到期时间与采样字节／次数。
2. 独立进程只持有本设备／会话的 scoped token。Core 不取得 Docker socket、宿主 shell、
   ADB 通用命令或 Android 管理凭据。
3. 采集前以固定 argv 查询前台包及版本；不是允许包或未完成启动时立即结束。
   `uiautomator dump` 仍使用固定 argv，禁止接受网页／模型传入的 shell 字符串。
4. XML 在本机解析。拒绝登录／账号绑定页面、密码属性、EditText、系统通知和其他包节点。
   只保留经当前版本样本确认的正文／标题资源 ID；无法确认页面类型时不提交内容。
5. 采集后再检查前台包、会话有效性和撤销状态；任一改变时丢弃结果。不得后台持续采集。
6. 信息流标题／摘要仅标 DISCOVERED；可核实的当前屏幕正文片段才可标记 FETCHED，明确只覆盖
   当前可见段落，不能称已读全文。
   图片控件没有文字时明确无正文，不假称完成图像识别；无帖子链接则使用设备／会话来源，
   不冒充特定帖子 URL 的读取结果。
7. 同一次观察记录设备、会话／同意 ID、采集时间、包名／版本、UI_XML 类型、原始 XML 摘要、
   有界文字及覆盖范围。复用已有依赖链，将主人触发事件作为删除根。

截图、视觉 Provider、点击、滑动、输入和自动打开帖子均不属于此合同的首次实现。
真实测试由主人将游客 App 停留在目标页面后进行；不能通过自动漫游凑齐样本。
