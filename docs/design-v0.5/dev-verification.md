## 开发实例操作

服务器目录内使用 `docker compose -f compose.json ps` 查看状态，`docker compose -f compose.json stop` 停止开发实例。使用 `docker compose -f compose.json exec -T api /app/.venv/bin/python -m companion status` 查看功能状态。身份令牌只保存于权限为600的 `dev.env`，开发数据库与遗忘日志分别在 `data/`、`privacy/`。
