# v0.5 短期交互状态

`AffectEngine` 从明确的主人沟通反馈形成短期交互参考：简短/详细、分步、暂停/继续话题、尝试新话题。没有固定人设，也不根据“我很难过”等描述猜测用户或 AI 的情绪。

每次变化保留原事件、维度、前后状态、原因、置信度和独立到期时间。普通聊天不会续期，另一个维度的新反馈也不会续期旧维度。快照在没有后台进程或模型调用的情况下按时间返回中性。事件删除会撤销相关状态；旧备份恢复重放相同撤销。

状态按 companion 身份保存，跨会话和重启有效；Context Builder 将它作为有来源的表达参考。它不会写入长期 Memory/traits，不授予工具权限，不改变承诺。`GET /internal/v2/affect` 需主人 control token。默认 `affect_enabled=false`，默认有效期 180 分钟，证据数量有界。

本阶段用确定性、完整匹配的少量反馈句式，避免未经验证的情绪推断。自然语言模糊反馈保持中性，后续可在有标注数据时增加经过验证的规则。自动化覆盖新会话、重启、独立 TTL、引用文本、外部注入、证据撤销和恢复。
