## 实现

| 范围 | 当前行为 |
|---|---|
| 用量与费用 | 本地 token 估算和输出上限按配置费率预留；返回 usage 后结算并记录误差。显式付费开关、原金额/次数/并发上限、独立 journal 与 UNKNOWN 保留。费用是配置价估值，账单对账另记 |
| 模型发送 | 每次请求使用独立 client 和借用的 transport；最终绑定实际发送正文、目的及凭据，统一最后时刻的授权与 lease 检查。错误正文或错误 HTTP 中已有的 usage 先记账，再传播错误 |
| 最近对话 | 默认关闭；显式批准后，仅使用同窗口、主人私聊、同会话的至多四个完整 SENT 轮次。原接收签名、输入/回复回执、字节裁剪、来源和 privacy epoch 均复核，已有调用时上下文快照必须存在 |
| 运行观察 | CLI 只读现有 SQLite/WAL、队列、预算和资源；摘要不初始化或修复状态。HTTP 仅支持显式 IP，固定字段投影、正常 TLS 验证、五秒整体期限及完成时新鲜度校验。采样失败、间隔和重启均分段 |
| 验证入口 | PowerShell 检查为子进程固定当前工作树的 Python 导入路径，支持复用虚拟环境且不误测另一个 checkout |

Core 仍为组合根；模型适配层不持有存储、审批或投递职责，AstrBot/Core 仍通过 HTTP v1 协作。
本批没有数据库迁移、第二份队列或账本。旧金额、删除回放、投递不确定和窗口剩余额度继续保留。
