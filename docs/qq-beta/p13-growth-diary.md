# P13 C/D/F4：真实成长与私人日记准备

源码基线：`eb5143500bed5395bb45f2a2cc20335da9988491`。本包复用 P12 已合并的
Affect、Interest、Timeline、Reflection、Goals、Diary 和 Consolidation。
本轮只做离线修复、合成回归和申请/审阅准备。当前业务状态没有新回读，记为
`NOT_RECHECKED`；真实反馈、日记、Reader、自然日、主动分享及手机确认均为 `NOT_RUN`。
`private_beta_ready=false`，`production_ready=false`。

## 精确否决与迁移

`0018_reflection_goal_lineage` 只给原 `goals` 表增加可空
`reflection_suggestion_id` 外键和索引。Consolidator 仅为其新提出的反思派生目标记录
准确 suggestion ID，并将该 ID 纳入派生候选幂等键。相同文本/相同原始来源的独立目标仍
独立存在；不能用文本相似或来源重叠猜测归属。普通目标与主人承诺的创建接口没有扩大。

| 否决时状态 | 结果 |
| --- | --- |
| 候选、未开始的目标/读取 | 撤销未来意图；未开始的 Reader 请求取消，不能再 accept/claim/dispatch |
| 已开始或无法确认是否开始 | 目标意图取消，步骤保留 `EXECUTION_UNCERTAIN`；已开始的 Reader 请求记 UNKNOWN，保留原预留、实际计数和时间，不退款或重试 |
| 已完成且有真实来源结果 | 保留 DONE 与既有结果，不把主人否决假设写成“从未执行” |
| 其它独立目标/主人承诺 | 不受该 suggestion 的决定影响 |

反思重新改为 `ACCEPT_AS_HYPOTHESIS` 不会自动重启已取消目标。反思读取仍保留可审计的决定
状态；聊天里的反思列表只展示待核对、待补充证据或已采纳的暂时假设。任何状态都不改变
事实、权限、承诺、预算或发信次数。Reader 最终 `validate_read` 在已有身份/来源 grant
检查之外重验原 goal lease，暂停或否决后的旧工作不能再通过该派发检查。

**兼容边界**：已有目标没有可靠的 suggestion 归属证据，迁移保留所有旧列，新增列为 null，
不自动回填或取消。启用旧库中的 Goals 前，要对迁移前无归属候选单独人工审查；不能声称
其历史否决级联已完整。存在非空关联时降级被拒绝，避免静默丢失否决约束。恢复仍先迁移、
回放最新 ErasureLedger，再检查目标/反思/日记删除闭包；原预算与窗口日志不能回退。

## C：一个真实自然日怎样审阅

使用 [自然日审阅模板](p13-growth-day-review.template.json)。它是空白记录格式，不是
批准、数据认证器或第二套观测库。复制到已获准的私密目录后，引用现有
[P12 feedback](p12-beta-feedback.template.json)、Inspector 与 E 的观察清单；真实正文、
日记、账号、地址和审批原件不放入公开报告。

每条 `source_rows` 至少记录私有来源引用、event/trace 的匿名摘要、原始 UTC 时间与批准
时区下的自然日期、source、coverage、内容哈希、规范目标摘要、原始批准和未遗忘核验。
完成读取还要有实际 FETCHED/WATCHED 回执及 goal/result 关联；标题、失败、UNKNOWN、模拟
事件分别标注。重复内容或目标最多计一次独立读取，同一天多个读取只计一个自然日。

1. C1 仅核对当前主人正文对应的 SHADOW reason/TTL；引用/转发文字不当作主人反馈。
   没有反馈是 neutral/unknown。到期或源撤销后重新预览，核对其已消失。表达启用另批。
2. C2 将 `owner.preference` 与 `self.interest` 分别列来源。状态只是原始证据的统计投影，
   不证明固定人格、真实已过天数或持续在线。一次表现不能认定稳定兴趣。
3. C3 对每条“发现/不确定/下次问题”核对原文出处，再记录主人决定和关联目标状态。
   记录已否决但仍能继续执行、无出处偏好、重复文章计成新天数等具体错误。
4. C4 真人按 1–5 分评价自然度、记忆、日记真实性、兴趣来源和主动性，并记录理由。
   未审阅就是 null，不填中间分。纠正次数和错误率只有明确分母才汇总。

1/3/7/14/30 日是后续审阅里程碑。实际日期来自获准原始来源与人审，不来自导出日期、测试
时钟或目标数。缺失观察段单独记录，不能算连续健康；API 可读、Worker 推进、任务完成、
Outbox SENT 和手机看见分开引用 E 的证据。本轮没有填入任何真实日期或评分。

## D：一篇实际日记及翌日接续

[独立日记申请模板](p13-private-diary-request.template.json)分开列出生成、翌日接续、
修改、删除和隔离恢复范围；每项批准摘要都为空。模板里的次数是拟申请上限，不是现成许可。

- 先新回读当前 STOP、身份、精确镜像/配置、schema、privacy epoch 和三类独立日志。
  选一个确实结束的自然日，核对 `DiaryRepository.sources(day)` 的完整集合与原始证据。
  现有服务按日选来源，并不是任意子集授权器；若集合含未批准来源，先停下收窄操作或重新
  审查完整集合，不能把申请中的 hash 当作运行时已实现的新增 grant。
- 建议首篇只允许原 Diary 的一次模型尝试，独立日记预算、费用与账户范围另批；反思默认
  不同启。若采用 Consolidation，自动记忆抽取、Goals/Reader/主动分享仍关闭。来源不足
  返回 SKIPPED，UNKNOWN 不补调用。`diary_auto_share=false`，日记生成不创建 Outbox。
- 主人逐段审核来源是否支持、是否调换主体、是否把发现标题写成阅读完成、是否编造经历，
  并记录遗漏和隐私内容。事实不支持的段落单独计数，不用“生成成功”替代审阅。
- 修改单独绑定 entry/day/timezone 与准确新文本；删除单独绑定原日期和完整删除范围。
  翌日接续使用仍合法的原始事件/事实，不能用日记当事实证据。下一实际日期未发生时保留 null。
- 另批删除前加密备份与新隔离目标，技术性禁止 QQ/模型/Reader 出站；最新 Ledger 回放后，
  旧日记/修订/副本不复活，独立日期不误删。反思决定或目标意图的历史快照不能替代新的
  执行审批；任何恢复后的继续执行仍需准确当前复核。

D2 的一次 Reader 与 D3 的第一次主动私聊是后续独立范围：先看 SHADOW 目标/草稿，再核对
准确 R6 grant、目标、时限、预算和实际结果。私人草稿不授权读取或发送。首次发送另批准确
主人、不可变正文、来源、免打扰/冷却/次数和取消，最多一条原 Outbox；SENT 与手机确认分栏。

## F4：PAD 只读对照设计

PAD 文献将情绪状态分为 Pleasure、Arousal、Dominance 三个维度，并用人的量表评估这些
维度；它没有证明本项目可以从一句 QQ 文字推断主人的心理状态或生成稳定人格。
参见 Mehrabian 的[原始研究摘要](https://pubmed.ncbi.nlm.nih.gov/7557355/)。
Bradley 与 Lang 的 SAM 研究比较了人对图片刺激的自报评分；将其用于本项目的回复表达，
需要另做产品验证。这是本项目的限制判断，不是原研究对聊天机器人的结论。
[论文与摘要](https://doi.org/10.1016/0005-7916(94)90063-9)。

本轮不实现 PAD 数值、后台循环、模型情绪推断或 Prompt 注入。候选只读研究可在另批资料
范围内，比较“现有明确反馈 SHADOW”与“人工标注表达维度的纸面候选”，建议至多 12 份
记录、每份最多两种静态表达、每源最多 500 字；这些是提案上限。初步研究不调用模型或
发送候选，不采集隐含心理诊断，不复制第三方量表题目或实现。

先由主人冻结样本/评分口径和是否值得继续的标准，匿名顺序比较自然度、相关性、撤销后的
可理解性与额外认知负担，记录偏好及原因。没有明确可复核的净收益就保留原路径；样本少
则报告未知。即使未来获准实现，也只能影响已批的表达候选，不能影响事实、权限、费用、
承诺、目标执行或消息次数。本轮样本数、偏好率、收益结论均为 null。
