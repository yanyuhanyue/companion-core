# P8-C.1 公开准入材料隐私审查

范围：PR #30 的公开准入文档、机器记录、Schema、配套实验/测试与 PR 描述。
检查仅针对这些公开材料，不读取真实数据库、凭据、登录卷或私密目标清单，不连接目标主机。

## 修正与验收

原目标端点字段改为 `private_target_ref` 与 `target_inventory_sha256`；
公开别名 `private_target_final` 不包含连接参数，实际清单及访问权限留在已授权私密记录。
清单未盘点，hash 保留 null；来源仍为 `USER_SUPPLIED_NOT_PROBED`，不据匿名引用推断已部署或已验证。
Schema 校验匿名引用格式、hash 和来源范围，不固定某台机器，也不允许回填 host/ssh_port。
六项独立审批及原 v2 合成实验保留，实机门禁仍为 BLOCKED/DISABLED。

配套隐私回归只扫描明确列出的 P8-C 公开材料，不将正常网络实现、项目公共 API 或全部历史文档当成私密数据。
它检查非示例网络地址、带值 SSH 端点字段、数字 QQ 身份、凭据样式和私密绝对路径；
允许文档示例地址、回环和未指定监听地址。失败仅输出仓库相对文件名与类别，绝不打印命中值或原文。
这是一项有界防回归检查，不能证明任意自由文本均已匿名化，也不扫描已推送历史或远端 artifact。

红例在原公开内容上命中三份目标材料；日志只记类别和相对文件路径。
修正后的 `scripts/check.ps1` 定向运行隐私与原准入测试：Ruff 通过、20 项通过（3.69s）。
随后增加 SSH 字段格式回归并再次定向验证；最终结果与准确提交的 CI 由协调记录/PR 检查展示，
原 HEAD 的成功 CI 不作为本次脱敏通过依据。初版路径规则误把 URL 尾部当盘符，已缩窄边界后重做红例与绿例。
