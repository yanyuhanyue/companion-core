# 主人黑话学习（2026-10-30）

从主人自己的私聊里学主人特有的说法（自造词、缩写、谐音、外号、两人之间才懂的叫法），
推测含义后，只用来让她听懂主人，不拿来模仿。机制参照 MaiBot 的黑话学习
（`src/learners/jargon_learner.py`、`jargon_miner.py`，提交 `c6429547`），
调研见 [MaiBot 机制调研](plans/2026-10-30-maibot-mechanisms.md)。实现在 `companion/jargon.py`。

## 流程

| 步骤 | 做什么 | 模型调用 |
|---|---|---|
| 扫描 | life worker 每轮读取新的主人私聊文字；已学到的说法在新消息里出现就记一次使用，并记下这条消息的编号 | 无 |
| 抽取 | 攒够 12 条新消息（`batch_messages`）后调用一次，找出主人特有的说法。说法必须原样出现在它引用的消息里，否则丢弃；涉及敏感信息的丢弃 | 每批 1 次 |
| 推断 | 一个说法用到 4 次和 25 次时，各根据最近的用法推断一次含义。模型同时给出一般含义和主人的含义，两者不同或是主人自造的才算黑话；模型不确定时不算 | 每个说法最多 2 次 |
| 使用 | 主人当前消息里出现已推断的说法时，聊天上下文附一条“主人用语参考”，注明是推测、不要模仿、不要解释给主人听 | 无 |

MaiBot 推断一次要三次调用（带上下文、只看词、比较两者）。这里用一次结构化输出代替，
费用有上限：每天默认最多 $0.02（`jargon.daily_micro_usd`），并且后台调用会给聊天让路。

## 只读什么

- 只读主人发出的私聊文字（`source='qq.onebot'`、`actor_id='owner'`、`privacy_scope='private'`）。
  引用、转发、群聊、第三方内容、`/` 开头的指令、日记和控制指令都不读。
- 不保存上下文原文，只保存消息编号；推断时回查原消息，原消息不在了就取消。
- 需要主人授权里的 `memory` 用途（授权已有，并且 `memory_scope=owner_private`）。
  有界真实文本窗口只用审批过的事实，不注入黑话。

## 遗忘和删除

- 来源消息被遗忘或过期时，删除它在所有说法里的引用；说法失去任何一条来源就清空推断出的含义，
  重新累计；失去全部来源时整条删除。遗忘处理器登记为 `jargon`。
- 主人在控制台“记忆 → 黑话”里可以忘掉某个说法。忘掉的说法不会再被学习，聊天记录不受影响。

## 配置

`[jargon]` 表：`enabled`（默认开）、`daily_micro_usd`、`batch_messages`、`max_output_tokens`、
`max_attempts`、`max_context_terms`。控制台“记忆与日记”分组里叫“学习主人的黑话”。

## 数据

迁移 `0053_owner_jargon`：`jargon_terms`（说法、来源编号、使用次数、状态、含义）和
`jargon_work`（抽取和推断的付费任务队列；结果不明的调用记为 UNKNOWN，不重放）。
